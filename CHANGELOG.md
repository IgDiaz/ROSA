# Changelog

## 0.3.1 — Independent SDK — 2026-09-28

- Publish the robotics toolkit as an independent public repository.
- Retain context, policy, runtime, local AI and ROS 2 adapters, agent gateway,
  schemas, examples and the functional local simulation console.
- Keep the website application and deployment configuration outside the SDK.
- Include privacy, security, MIT, CDT and third-party notices.

## 0.3.0 — ROSA / Minerva — 2026-09-28

- Adopt Robotics Operational Systems and Agave and the `rosa` namespace.
- Preserve scoped context, deterministic checks, expiring proposals and
  idempotent simulated execution.
- Provide optional ROS 2 observation, local Ollama and signed context export.

The earlier combined website/toolkit repository is not imported into this
repository's Git history. MIT and CDT attribution are retained.
